    3. 交互按钮与状态

    #btn-toggle 启动 / 暂停

    • Running：红底「暂停」+ Pause 图标
    • Paused：绿底「启动」+ Play 图标
    • Blocked：禁用或仅允许「启动检查」
    • 点击暂停：打开确认模态，文案说明将停止新订单
    • Loading：disabled + 文案「处理中…」

    #btn-tick 立即执行一轮

    • Paused / Blocked / Error：disabled
    • Running：可点；点击后 800ms loading
    • Stale：可点，但顶部 Warning 条提示对账

    #btn-recon 刷新对账

    • 仅 Stale / Warning / Error 场景高亮
    • 成功后 recon-pill → Fresh

    #btn-clear-runs 清空历史

    • ghost 次要操作
    • 需确认（本原型用 confirm）
    • 清空后 Empty 状态

    语言切换 中文 / EN

    • 只替换文案节点，不改栅格
    • 数字 / Edge / 阶段英文 ID 保持
    • 长市场标题一律 truncate

    Hybrid 展开详情

    • 默认折叠：一眼看状态
    • <details> 展开字段级信息
    • 不使用嵌套卡片

    确认暂停自动交易？

    暂停后系统将停止提交新订单；已有挂单与持仓退出策略仍按规则处理。可随时重新启动。
