# Polymarket Weather 小白上手指南（macOS）

这份说明写给**第一次使用**的人：  
不需要会写代码、不需要会用终端（Terminal）。  
如果有人给你发了 `Polymarket Weather.dmg` 或 `.app`，按下面做就行。

> **先记住三句话**  
> 1. 第一次请选 **「纸面自动交易」**，它**不会**真实下单。  
> 2. **私钥 = 钱包的总钥匙**。任何人拿到都能转走你的钱。  
> 3. 本软件**不能保证赚钱**，只是帮你研究/自动化天气相关市场。

---

## 1. 这个软件是干什么的？

它是一个装在你 Mac 上的本地小工具：

1. 自动打开浏览器里的操作页面；
2. 帮你扫描 Polymarket 上的**天气相关市场**；
3. 结合天气预报估算机会；
4. 在你明确允许、并通过安全门槛后，才可能走真实下单。

它**不是**：

- 交易所官网；
- 帮你「保证稳赚」的理财产品；
- 需要你把密码发给别人的云服务。

数据默认只存在你这台电脑上。

## 2. 你需要准备什么？

| 需要 | 说明 |
| --- | --- |
| 一台 Mac | 建议 macOS 12 或更新 |
| 安装包 | `Polymarket Weather-xxx.dmg` 或已经装好的 `.app` |
| 浏览器 | Safari / Chrome 都可以（软件会自动打开） |
| （可选）小狐狸 MetaMask | **只有你以后要做真实交易时才需要** |
| （可选）代理 | 如果打不开 Polymarket / 天气网站，可能需要 |

**第一次建议：**  
只安装、只完成设置、只跑「纸面模式」。  
**先不要**导出私钥，也**先不要**充值。

## 3. 安装（像装普通 Mac 软件一样）

1. 双击打开 `Polymarket Weather-0.1.0.dmg`（版本号可能不同）。
2. 把 **Polymarket Weather** 拖到 **应用程序（Applications）** 文件夹。
3. 弹出的磁盘可以右键「推出」。
4. 打开「启动台」或「应用程序」，找到 **Polymarket Weather**。

### 如果双击后提示「无法打开 / 来自身份不明的开发者」

这是 macOS 的正常安全提示（本地签名版本很常见）：

**方法 A（推荐）**

1. 在「应用程序」里找到这个软件；
2. **按住 Control 键再点**图标（或右键点击）；
3. 选 **打开** → 再点 **打开**。

**方法 B**

让懂电脑的人帮你在终端执行一次（你自己不熟可以跳过）：

```bash
xattr -dr com.apple.quarantine "/Applications/Polymarket Weather.app"
```

## 4. 第一次启动会发生什么？

1. 双击软件。
2. 菜单栏右上角附近可能会出现 **PW** 小图标（状态栏菜单）。  
   如果没有，也可能弹出一个小控制窗口：打开面板 / 暂停 / 日志 / 退出。
3. 浏览器会自动打开一个本地页面，地址类似：

   `http://127.0.0.1:xxxx/setup`

   这是**你电脑里的页面**，不是网上别人的网站。
4. 第一次会进入 **设置向导**。按步骤点「继续」即可。

### 重要：关掉浏览器 ≠ 关掉软件

- 关掉浏览器标签：后台还在跑。
- 要彻底退出：用状态栏菜单 / 控制窗口里的 **Quit（退出）**。

## 5. 设置向导怎么填？（按推荐来）

向导一共大约 7 步。下面用「小白默认」写法。

### 第 1 步：本地健康检查

一般直接点继续。  
它会确认：

- 数据文件夹能不能写；
- 数据库能不能初始化。

你不用改路径。

### 第 2 步：运行模式（很重要）

| 选项 | 小白要不要选 | 含义 |
| --- | --- | --- |
| 观察 | 可以 | 只看、只分析，不产生模拟单 |
| **纸面自动交易** | **推荐默认** | 自动扫描分析，**模拟下单记录**，不花真钱 |
| Micro Live | 先不要 | 真实小额交易，门槛很多 |
| Full Live | 先不要 | 更完整的真实自动交易，风险更大 |

**完成设置不会自动开始真实交易。**  
就算以后选了 Live，也要你在 `/app` 里自己点启动，并过一堆检查。

### 第 3 步：钱包与 Polymarket

**第一次纸面模式：这一步可以先空着，继续往后走。**

只有你准备真实交易时，才需要：

- 私钥（Private Key）
- Funder 地址（资金/代理钱包地址，有时和签名地址相同）

详见下面第 6、7 节。

### 第 4 步：连通性

可以勾选「运行只读连通性探测」。

- 成功：说明能访问市场/接口。
- 失败：常见是网络/代理问题。  
  **失败不会删掉你已经保存的设置。**

如果你在中国大陆网络环境，可能需要在「高级 → 代理」填本地代理，例如：

```text
http://127.0.0.1:7890
```

具体端口以你自己的代理软件为准（Clash / Surge 等）。

### 第 5 步：风险预设

纸面模式选 **「纸面默认」** 即可。

以后若做极小额实盘，再考虑：

- Starter Live：每单约 1 USDC 量级  
- Cautious Live：每单约 2 USDC 量级  

金额仍受软件硬顶限制，不能随便拉很大。

### 第 6 步：天气与通知

- 天气数据源：默认 **open-meteo** 即可（通常**不需要**天气 API Key）。
- Telegram：可选。不会配置就先关掉。

### 第 7 步：就绪复查

这里是检查清单。你会看到一些英文状态，例如：

- `configured` / `missing`：配了 / 没配  
- `ok` / `failed`：检查通过 / 失败  
- `not_yet_verified`：本地还没完全验证（正常，尤其没填钱包时）

看完点 **完成设置并进入 /app**。

## 6. 你其实不一定需要「Polymarket API」

很多小白会问：

> 「我要去 Polymarket 哪里申请 API Key？」

对这个软件的主路径来说：

### 通常需要的是「钱包」，不是网站后台一串 API 申请表

真实交易路径主要用：

1. **钱包私钥**（用来签名）  
2. **Funder 地址**（资金所在地址；软件也可尝试从私钥推导签名地址）

可选/进阶项（先别碰也行）：

- Relayer 相关密钥（高级）  
- 天气 API Key（默认 open-meteo 常常不需要）  
- Telegram Bot Token（只为了收通知）

### 所以：

- **纸面模式**：可以完全不填钱包。  
- **实盘模式**：准备一个**专用小额钱包**，再导出私钥。  
- **不要**把主钱包、存了很多钱的钱包私钥填进来。

## 7. 小狐狸（MetaMask）私钥怎么找？（仅在你决定做实盘时）

> **强烈建议**  
> - 新创建一个**只给这个软件用**的钱包  
> - 里面只放你亏得起的很小金额  
> - 永远不要把私钥发到微信/QQ/邮箱/截图群  
> - 不要在网吧、别人电脑、不明网页上导出  
> - 导出后尽快关掉显示，不要拍照

### 7.1 先搞懂：助记词 ≠ 私钥，但都一样危险

| 名称 | 是什么 | 危险程度 |
| --- | --- | --- |
| 助记词（Seed / Recovery Phrase） | 12/24 个英文单词 | 最高。等于整组钱包 |
| 私钥（Private Key） | 一长串 `0x` 开头的十六进制 | 最高。等于这一个账户 |
| 钱包地址（Address） | `0x` 开头较短的一串 | 可以给人看，用来收款 |

软件设置页要的是 **私钥**，不是助记词。  
但请同样当成「银行卡+支付密码」保管。

### 7.2 在电脑版小狐狸导出私钥（示意步骤）

不同版本菜单位置可能略有差别，大体如下：

1. 打开浏览器里的 **MetaMask（小狐狸）** 扩展。
2. 确认当前网络稍后能用于 Polygon（Polymarket 常用 Polygon 相关生态；若你完全不懂，先停在纸面模式，找懂的人帮你看）。
3. 点右上角账户图标，确认你要导出的是**专用小账户**。
4. 进入该账户的详情 / 账户详情（Account details）。
5. 找到 **显示私钥 / Export Private Key / 导出私钥**。
6. 输入你的 MetaMask 密码。
7. 复制私钥（通常以 `0x` 开头，很长一串）。
8. **只粘贴到本软件设置页的「私钥」密码框**，不要粘到别的地方。
9. 导出窗口立刻关闭；不要截图保存到相册。

### 7.3 Funder 地址填什么？

常见两种情况：

**A. 最简单（很多个人用户）**

- 勾选设置里的「用私钥推导地址，并在 funder 为空时填入」  
- 或把小狐狸里显示的账户地址（`0x...`）填到 Funder

**B. 你用了 Polymarket 的代理钱包 / 特殊登入方式**

- 签名地址和资金地址可能不是同一个  
- 这种情况请让已经会用 Polymarket 的人帮你确认 Funder  
- **不要猜着填**

### 7.4 填完后软件会怎么保存？

- 私钥进 **macOS 钥匙串（Keychain）**，不会写进明文配置文件给你随手打开看到。  
- 页面上只显示「已配置 / 未配置」，**不会把私钥原文显示出来**。  
- 留空再保存 = **保留原来的私钥**，不是删除。  
- 要删除必须勾选「删除已保存的私钥」这类明确选项。

## 8. 进入 /app 之后怎么用？

设置完成后，浏览器会到 **`/app`**（操作台）。

### 纸面模式日常

1. 确认模式是 **纸面 / Paper**。  
2. 需要时再点 **开始 / Start**（启动自动循环）。  
3. 想停就点 **暂停 / Pause**。  
4. 也可以点「运行一次」做单次检查（如果页面有这个按钮）。

### 状态栏菜单（菜单栏 PW）

| 菜单 | 作用 |
| --- | --- |
| Open Dashboard | 重新打开浏览器页面 |
| Pause Autopilot | 暂停自动循环 |
| View Logs | 打开日志 |
| Quit | **退出整个软件** |

### 再次打开软件

- 已经完成过设置：通常直接打开 `/app`  
- 设置和历史会保留  
- 如果软件已经在运行，再点一次一般会打开现有页面，而不是开两个

## 9. 什么时候才能碰「真实交易」？

请同时满足下面这些，才考虑 Micro Live：

1. 纸面模式已经正常跑过一段时间，你看得懂页面在干什么；  
2. 使用**专用小额钱包**，钱是你愿意亏光的；  
3. 私钥、Funder 已配置，就绪检查不再是大片失败；  
4. 你理解：限价单、可能部分成交、网络失败、地区限制都可能导致不符合预期；  
5. 你知道 **暂停 / 退出** 在哪里。

即便如此：

- 完成设置 **不会**自动实盘；  
- 还需要你在 `/app` 明确启动；  
- 还可能被合规地区、对账、风控、白名单等拦住——这是保护，不是坏了。

**本指南不教你如何绕过风控或地区限制。**

## 10. 数据存在哪里？卸载怎么卸？

### 数据位置（升级软件一般不会丢）

```text
~/Library/Application Support/Polymarket Weather/
  config.env          ← 非机密配置
  data/...db          ← 本地记录
  logs/               ← 日志
  runtime/            ← 运行状态
```

私钥在 **钥匙串**，不在上面这个明文文件里。

### 卸载

1. 先 Quit 退出软件。  
2. 把「应用程序」里的 Polymarket Weather 丢进废纸篓。  
3. 若要连历史一起删（可选）：

```bash
rm -rf "$HOME/Library/Application Support/Polymarket Weather"
```

钥匙串里的项可在「钥匙串访问」里搜索 `polymarket-weather` 后手动删除。

## 11. 常见问题（FAQ）

### Q1：页面打不开？

1. 确认软件还在运行（菜单栏有 PW 或进程还在）。  
2. 用菜单 **Open Dashboard**。  
3. 看日志里是否有启动失败。  
4. 换一个端口通常软件会自己处理；不要自己乱改系统。

### Q2：我没有私钥，能用吗？

能。选 **纸面自动交易**，钱包先空着。

### Q3：open-meteo 要 API Key 吗？

一般不需要。先保持默认。

### Q4：Telegram 一定要配吗？

不用。那是通知，可选项。

### Q5：为什么就绪检查有很多红色/黄色？

没配钱包、没做过对账、网络不通时很常见。  
纸面模式不要求你全部变绿。

### Q6：别人让我「把私钥发给他帮你配置」？

**一定是诈骗。** 立刻拒绝。

### Q7：软件能保证赚钱吗？

**不能。**  
交易有损失本金的风险。纸面模式请先用够。

### Q8：我只是关掉了浏览器，第二天电脑很卡？

可能软件还在后台。用 **Quit** 退出。

## 12. 绝对不要做的事

1. 不要把私钥发到任何聊天软件。  
2. 不要用存着大额资金的主钱包。  
3. 不要在视频通话里展示私钥。  
4. 不要把 `config.env`、日志、数据库打包发给陌生人（里面可能有敏感痕迹）。  
5. 不要在没理解模式的情况下选 Full Live。  
6. 不要以为「点了完成设置」就已经在自动赚钱。

## 13. 推荐学习路径（最稳）

```text
第 1 天：安装 → 设置选纸面 → 进入 /app → 先观察界面

第 3 天以后：如果仍想实盘，再单独准备小额钱包，小步前进
```
