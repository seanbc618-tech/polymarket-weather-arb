# Polymarket Weather 0.1.4

Friend-share macOS packaging for the compact console V4 `/app` experience.

## What’s new in the console

- **Compact V4 console** — denser first screen so health, safety, and PnL fit without endless scrolling.
- **Collapsed completed Setup / mode controls** — after setup, completed controls use a compact command toolbar instead of large demo-style panels.
- **First-screen checks** — local readiness checks sit side by side with safety status.
- **Safety / PnL / positions / funnel** — live-oriented status blocks using real persisted data (not demo scenario controls).
- **Compact real-data tables** — candidate markets show eight rows before expansion; recent runs show six before expansion.
- **Expandable history** — expand tables when you need more rows; keep the first screen quiet by default.

Mode changes, pause, and one-tick controls still work through the existing autopilot path. This release does not change trading strategy, risk caps, or execution safety gates.

## Dual architecture downloads

Native apps for **Apple Silicon** and **Intel** Macs (not universal binaries). Download the matching file:

| Mac | Download |
| --- | --- |
| Apple Silicon (M1 / M2 / M3 / M4 …) | `Polymarket Weather-0.1.4-macos-arm64.dmg` |
| Intel | `Polymarket Weather-0.1.4-macos-x86_64.dmg` |

**Which one do I need?**

1. Apple menu → **About This Mac**.
2. Chip says **Apple M…** → use `arm64`.
3. Chip says **Intel** → use `x86_64`.

Builds are ad-hoc signed and **not notarized**. First launch may need right-click → **Open**.

## Upgrade

1. Status menu → **Quit** the old app completely.
2. Open the new DMG and drag **Polymarket Weather.app** to Applications → **Replace**.
3. Config, database, and logs under `~/Library/Application Support/Polymarket Weather/` are kept; secrets stay in Keychain.
4. Delete the old DMG. There is **no auto-updater**.
